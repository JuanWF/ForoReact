🔍 BASE DE DATOS MONGODB

Colecciones:
  ┌─────────────┬──────────────────────────────────────┐
  │ users       │ Usuarios del sistema                 │
  │ posts       │ Posts del foro                       │
  │ comments    │ Comentarios (con parent_id)          │
  │ votes       │ Votos polimórficos                   │
  │ trends      │ Tendencias/tags populares            │
  └─────────────┴──────────────────────────────────────┘

Relaciones:
  • User → hasMany → Posts
  • User → hasMany → Comments
  • User → hasMany → Votes
  • Post → belongsTo → User
  • Post → hasMany → Comments
  • Post → hasMany → Votes
  • Comment → belongsTo → User
  • Comment → belongsTo → Post
  • Comment → belongsTo → Comment (parent)
  • Vote → morphTo → Votable (Post/Comment)

Tipo: Referencias (IDs) - No embebidas

🚀 CÓMO INICIAR

1. Configurar .env
   ─────────────────
   DB_CONNECTION=mongodb
   DB_HOST=127.0.0.1
   DB_PORT=27017
   DB_DATABASE=forodb

2. Poblar datos de prueba
   ───────────────────────
   php artisan db:seed --class=ForoSeeder

3. Iniciar servidor Laravel
   ─────────────────────────
   Terminal 1: php artisan serve

4. Compilar assets React
   ──────────────────────
   Terminal 2: npm run dev

5. Visitar aplicación
   ──────────────────
   http://localhost:8000

6. Login de prueba
   ───────────────
   Email: admin@forodb.com
   Password: password
